# Preset Texture Assets

This folder contains texture files used for presets and effects. Place your custom image files (PNG/JPG/WebP) here, organized by effect type.

## Folders
- `/borders` - Custom border templates/textures.
- `/dust` - Dust and scratches textures.
- `/grain` - Custom grain textures.
- `/lightleaks` - Light leak overlay textures.

## Referencing Textures in Preset Editor
When specifying a texture file in the Preset Editor (Admins only), use a path relative to the `assets` folder:
- `textures/lightleaks/your_leak_file.png`
- `textures/grain/your_grain_file.png`
- `textures/dust/your_dust_file.png`
- `textures/borders/your_border_file.png`
